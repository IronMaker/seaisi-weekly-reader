# SEAISI Weekly Reader — Document Archive

This folder stores superseded SEAISI Weekly profile documents.

Current policy is intentionally lightweight:
- `docs/` keeps only active canonical profile documents.
- Older profile documents are moved here automatically by `SEAISI Weekly Cloud Autorun`.
- No semantic version governance, tags, releases, or changelog policy is enforced yet.
- Historical weekly reports and Pages run outputs are not moved here.
